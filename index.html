Getting Started

The DaB ANY Typical Section Utility is a high-performance parametric plug-in engineered for Autodesk® AutoCAD® and Civil 3D®. It streamlines urban design workflows by dynamically generating compliant roadway cross-sections and streetscape assemblies directly within your model space environment based on custom engineering parameters.

System Requirements

  • Host Application: Autodesk® AutoCAD® or Civil 3D® (Versions 2025 through 2026+)
  • Operating System: Microsoft® Windows® 10 or 11 (64-bit / x64 Architecture Required)
  • Runtime Environment: Microsoft® .NET Desktop Runtime 8.0 (automatically managed by modern AutoCAD installations)
  • User Interface Framework: Windows Presentation Foundation (WPF) Desktop Core

Installation & Quick Launch

The utility features a fully automated installer tailored for the Autodesk® App Store environment. Upon executing the .msi package, all binaries, dependencies, and menu configurations are deployed directly into your system's secure ApplicationPlugins directory.

To initialize the program within your active CAD workspace:

  1. Launch AutoCAD® or Civil 3D® (Version 2025 or newer).
  2. Look for the newly added DaB ANY CAD Tools tab on your top AutoCAD Ribbon menu interface.
  3. Click the Typical Section Utility button icon within the ribbon panel to dynamically toggle the interface control board.
  4. Alternative Command Line Method: You can also type DAB_TYPICALSECTION directly into the command prompt at any time to execute the app.

Licence Management

We provide a fully functional, risk-free 7-Day Free Trial for all new users to evaluate the parametric configuration engine. After the trial period expires, an Annual Subscription License is required to maintain access to section-generation and export routines.

Activation Steps

When the application launches, the licensing screen will display your unique, secure Hardware Fingerprint (Machine ID).

  1. Copy the generated Machine ID string directly from the prompt window.
  2. Submit this ID alongside your Autodesk App Store purchase token or invoice to receive your unique Annual Activation Key.
  3. Paste your key into the text field and click Activate License. The utility will store this authorization locally on your device for uninterrupted usage.

Privacy Policy & Security Compliance

We prioritize your project security and design confidentiality. In strict compliance with Autodesk App Store Developer Guidelines, our software operates using a fully transparent, localized architecture.

  • Zero Data Exfiltration: We do not collect, view, store, or transmit your CAD drawing files (.dwg), design variations, project metadata, or any corporate intellectual property.
  • Secure Local Storage: All licensing preferences and system configurations are saved locally on your workstation within the secure Windows Registry hive (HKEY_CURRENT_USER\Software\DAB_ANY\...).
  • No Tracking: This software operates free of third-party analytics trackers, background metrics collection, or behavioral profiling scripts. Network access is strictly restricted to secure API validation during software activation.

The comprehensive policy is published online for legal, corporate infrastructure, and IT clearance reviews. You can access the live updates directly here: DaB ANY CAD Privacy Policy & Terms.

How to Use the Application

The DaB ANY Typical Section Utility operates inside a native, dockable AutoCAD® Palette Set. This modern interface can float freely across multiple monitors or cleanly snap/dock to either side of your active drawing workspace—ensuring your design canvas remains fully interactive while you manipulate section parameters.

Managing the Palette Workspace

  • Docking/Floating: Click and drag the palette title bar to float it, or slam it against the left/right window edges to lock it alongside your standard AutoCAD Properties or Layer palettes.
  • Auto-Hide: Click the small arrow icon on the palette title bar to collapse the tool into a slim sidebar tab when screen real estate is limited. Hovering over the tab re-opens the suite instantly.
  • Persistent State: The palette retains its layout placement, dimension rules, and active session configurations even if you switch between multiple open drawings (.dwg).

Typical Section Element Catalog

Every roadway cross-section is built using modular, parametric structural building blocks called Typical Section Elements. These elements represent real-world infrastructure components engineered to interact intelligently with one another.

The element catalog is organized into functional categories visible directly within the WPF palette. To begin your design workflow, navigate through these groups to select the civil asset your project requires:

  • Roadway Geometry: Travel lanes, shoulders, and median strips.
  • Streetscape / Roadside Features: Sidewalks, pedestrian boulevards, and utility corridors.
  • Earthworks & Drainage: Curbs, gutters, side slopes, ditches, and daylight boundaries.
  • Barriers & Walls: Guardrails, retaining structures, and edge protections.

Selecting any item from this catalog acts as Step 1 of the design process, preparing the element to be populated into your active assembly sequence.

Assembly Composer Tree View

The Assembly Composer is the visual structural hub of the palette panel where your geometric cross-section is managed and constructed. When you select a component from the element catalog, it is immediately placed here into a linear, hierarchical tree view staging area.

Because roadway corridors are highly dynamic, the Assembly Composer gives you total control over the stacking sequence and physical arrangement of your components:

  • Interactive Rearrangement: If a sidewalk needs to sit behind a green boulevard strip instead of directly against a curb, you can instantly rearrange and re-order the elements within the tree hierarchy to modify their spatial layout.
  • Positional Stacking: The tree view acts as a parametric script. Elements are structurally appended sequentially from your baseline center point outward, ensuring that changing a component's position updates the attachment point for all subsequent elements down the line.

Once your layout sequence is finalized in the composer tree, you are ready to select individual elements and input their specific dimensions in the properties panel.

Element Properties & Parametric Control

Once a structural component is loaded into the Assembly Composer, its dimensional and engineering attributes are exposed within the Element Properties Grid. Adjusting these values allows for real-time manipulation of the geometric assembly before vector conversion inside AutoCAD.

Modifying properties establishes dynamic rules for the section generation engine. A comprehensive breakdown of key programmatic properties—including geometric profiles, variable cross-slopes, and material structure depths—is covered in depth within Chapter 3: Typical Section Elements.

Core Property Variable Types

  • Dimensional Variables: Explicit inputs governing physical spans (e.g., Lane Width, Sidewalk Width, Curb Height).
  • Structural Stratigraphy: Thickness and depth thresholds for subsurface civil layers (e.g., Asphalt wearing course, granular sub-base, topsoil depth).
  • Cross-Slope Percentages: Grade metrics defining drainage profiles and crown slopes expressed as geometric percentages (e.g., -2.00%).

Section Placement Options & Controls

Before committing your cross-section to your active drawing file (.dwg), the utility provides advanced layout, scale, and detailing controls to format the output data exactly to your firm's drafting styles.

A. Horizontal & Vertical Scaling Matrix

Unlike standard static blocks, the utility features an independent multi-axis scaling engine. Designers can establish an explicit Horizontal Scale Factor alongside an independent Vertical Scale Factor. This enables seamless generation of vertically exaggerated sections, which are highly critical for evaluating flat drainage catchments, structural utility clearances, or subtle boulevard grade differentials.

B. Material Hatching & Engineering Annotations

You can toggle advanced presentation parameters to prepare the structural section directly for sheet compilation:

  • Dynamic Structure Hatching: Automatically applies contextual AutoCAD hatch patterns (such as standard concrete, asphalt, or compacted earth styles) bounded precisely within the generated cross-section subgrade boundaries.
  • Automated Annotation Callouts: Generates smart leaders, structural thickness dimensions, offset markers, and cross-slope vectors directly on predetermined CAD layers.

Step-by-Step Design Workflow

To construct, validate, and place a typical roadway section, follow this core sequence within the WPF palette workspace:

  1. Select the Component: Navigate the element tree catalog and select your desired civil asset (e.g., Lane, Shoulder, Median, Sidewalk, Curb & Gutter).
  2. Populate the Assembly Composer: Click or assign the selected element to add it directly into the active Assembly Composer staging tree.
  3. Arrange and Sequence: Use the positional workspace options within the tree view to rearrange, re-order, or change structural attachment priorities as necessary.
  4. Inject Parameter Specifications: Select any stacked element to populate the Properties Grid. Input your exact project design criteria (e.g., lane width, sub-base material depth).
  5. Validate via Live Preview: Launch the detached, high-fidelity Live Preview Window at any time during your parameter tracking to interactively inspect and validate your assembly's physical geometry without cluttering your active drawing canvas.
  6. Set Drafting Configurations: Define your desired horizontal/vertical scaling ratios, toggle material layer hatching patterns, and activate automation annotations.
  7. Execute CAD Placement: Click the primary execution command button, then click an insertion coordinate inside your AutoCAD model space viewport to draw clean, layered vector objects instantly.

RoadWay Geometry Elements

Roadway Geometry elements serve as the core structural subassemblies for defining the driven, load-bearing surfaces of your cross-section corridors. These components dictate travel widths, cross-drainage grading, and subsurface pavement design depths.

Element Profile: LANE

The LANE element creates a parametric travel lane component complete with independent cross-slope controls and up to four distinct, cascading structural pavement layers.

Figure 3.1: LANE Geometric Width, Cross-Slope, and Stratigraphy Controls

Parametric Property Matrix

The table below outlines the programmatic fields exposed within the Element Properties Grid when a LANE component is actively selected in your Assembly Composer tree:

Property Field Default Value Unit Type Engineering Functional Description
Name LANE Alphanumeric The structural identifier label assigned within the Assembly Composer tree view canvas.
Lane Width 3.7 Meters (m) The total horizontal span length computed along the design plane from the element attachment baseline pivot.
Lane % Slope -2.0 Percentage (%) The cross-drainage fall rate of the lane surface. Input negative values to represent standard crown fall shedding outward.
Pave-1 Depth 0.05 Meters (m) Vertical depth of the primary wearing course asphalt layer. Set to 0.00 to omit structural drawing vectors.
Pave-2 Depth 0.05 Meters (m) Vertical depth of the secondary binder course asphalt layer.
Base Depth 0.15 Meters (m) Vertical thickness dimension of the graded granular aggregate structural base material layer.
Sub-Base Depth 0.30 Meters (m) Vertical thickness boundary of the select granular or stabilized subgrade layer material.
Lane Width Override Enabled OFF ON / OFF Toggle State logic engine modifier. Toggling to ON enforces custom dimension strings over standard parametric width tracking calculations.
Measurement Override 3.70 Meters (m) The alternative horizontal width boundary applied explicitly to geometry compilation routines when Override State is active.

🛠️ Programmatic Override Logic Explained

The Lane Width Override Enabled configuration allows for rapid section adjustments without altering core design templates:

  • When set to OFF: The vector calculation engine strictly utilizes the primary Lane Width variable value (Default: 3.7m) to draw structural links and hatch regions.
  • When set to ON: The utility completely forces an alternate layout vector pass using the dimensional criteria defined in the Measurement Override field. This is optimal for quickly modeling variable turn-bay lanes, localized road tapers, or custom intersection geometry rules without needing to change standard lane blocks.
